ASIM parsers do not run on the Sentinel data lake

Lake KQL does not support functions, and every ASIM parser is a function.

Analytics tier
Hunting query or analytics rule
Calls _Im_NetworkSession()
Source parsers run (KQL functions)
Tables return ASIM-shaped rows
Data lake tier
Hunting query or KQL job
Calls _Im_NetworkSession()
Source parsers never run
No ASIM-shaped rows
